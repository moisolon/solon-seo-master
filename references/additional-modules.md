# The 15 additional modules

Run each module; conditional applicability is explicit. Severity depends on demonstrated impact, not a hardcoded priority for the entire module.

| ID / module | Audit procedure and evidence | Correction and validation |
| --- | --- | --- |
| M01 JavaScript rendering | Compare initial HTML/rendered DOM on priority templates and routes; inspect failed resources, content revealed only by interaction, hydration, lazy loading and links | Repair SSR/SSG/rendering/resource access as appropriate; verify real served content, metadata and crawlable destinations; don't require framework migration by default |
| M02 Crawl budget/architecture | Map navigation depth and URL growth from parameters/facets, log crawl activity where available, duplicate routes and inventory gaps | Reduce actual crawl traps and unnecessary discovery, improve navigation; evaluate logs after change; crawl-budget optimization is especially relevant to large/frequently updated sites, no universal click-depth limit |
| M03 International | For multiple language/region versions test supported hreflang, reciprocity, canonicals, selector and locale routing; document version pairs | Fix alternate graph and local content; retest each affected locale; not applicable to a genuine single-version site |
| M04 Redirects/migrations | Capture hop/status/destination maps, loops/chains, traffic and backlinks for old URLs; compare migration inventories | Use permanent or temporary redirects according to intent; map equivalent content, avoid blanket home redirects; test old/new URL pairs and sitemap/internal references |
| M05 Advanced indexation | Inspect meta/header noindex, robots, soft 404, duplicate canonical signals, paginated and filtered URLs; corroborate with engine inspection | Align signals with intended discovery; robots blocking can prevent noindex being seen; retest served controls and later reported state |
| M06 Internal links | Crawl contextual links/anchors and breadcrumbs; reconcile inventories for orphan pages, broken links and important unreachable destinations | Add useful HTML links with meaningful anchors, repair targets and breadcrumb relationships; retest discovery/path, no arbitrary link-count or authority formula |
| M07 Images/video | Check accessible image/video URLs, responsive sources, size/dimensions, alt purpose, captions/transcripts, thumbnails, visible video prominence and applicable sitemaps/markup | Optimize appropriate media without hiding primary content; validate resource access, visible page and supported feature requirements; decorative alt can be empty |
| M08 Accessibility | Test keyboard/focus, headings/landmarks, label/error semantics, contrast, zoom and mobile flows on sampled templates; reference WCAG 2.2 | Repair within authorized UI scope or hand off; retest manually and with suitable tools; automated checks alone do not certify conformance or ranking benefits |
| M09 SEO security | Inspect HTTPS, malicious redirects, injected URLs/content, unauthorized sitemap changes and platform security/manual-action notices | Contain via authorized security workflow; preserve evidence and coordinate incident response; retest cleaned URLs and access; no intrusive vulnerability scan or broad security changes by default |
| M10 Ecommerce | When applicable inspect product variants/categories/facets, availability/price/currency, product identifiers, feeds, shipping/returns and Merchant Center diagnostics | Align page/schema/feed, handle out-of-stock/discontinued items by actual lifecycle; retest product/variant and checkout regression with non-purchasing tests |
| M11 Programmatic SEO | Sample generated templates and data quality, near duplicates, thin/doorway pages, empty results and scale; include edge and low-data cases | Consolidate, enrich with real value or restrict intended low-value outputs; validate representative generation rules; generated content/AI use alone is not proof of spam |
| M12 Competition | Compare actual local SERPs by intent, features, content gaps, credible sources and business relevance; capture query, market/date and sampled competitors | Prioritize distinctive coverage and existing-page improvements; no plagiarism, fabricated tool metrics or assumption that a vendor authority score is Google's score |
| M13 Advanced AI/GEO | Test platform-specific controls/bot access, accurate citations/entities and prompt matrix across available surfaces; separate verified bots from UA simulations | Use GEO reference; preserve training preferences, validate access and content, retest sampled responses; variability means nonappearance alone is not a defect |
| M14 Organic conversion | Reconcile landing pages, events, lead quality and revenue where accessible; test form paths without sending unsolicited real leads | Repair consent-compatible event/funnel issues; validate event deduplication and destinations in safe test mode; separate search clicks, analytics sessions, qualified leads and attributed revenue |
| M15 Observability/automation | Check audit history, release annotations, status/indexability/performance drift, logs and alert ownership | Establish baselines, detection and response procedures; schedule only on request; validate triggered/test alerts and delivery without unsolicited external messages |

## Cross-module traps

- An SEO plugin's green indicator is not an audit; inspect rendered output and duplicate metadata/schema from multiple plugins.
- A generic 301 is not always preferable to a correct 302/307. Preserve intent and HTTP semantics.
- `rel=canonical` is a signal, not authentication or an absolute indexing command. Engines may choose another canonical.
- Do not combine `Disallow` and `noindex` blindly to remove already indexed content. Private data needs actual access control.
- Do not use Google's Indexing API as a general article-submission endpoint; verify supported use cases. Consider IndexNow only for participating engines and eligible authorized URLs.
- Paid outreach, link purchasing, public profile edits, DNS/CDN controls, migrations and destructive removals are separate actions whose authority must be established, not inferred from a finding.
