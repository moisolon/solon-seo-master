# Google Search Console and Google Business Profile/Maps

Audit both. These are different products; neither is a substitute for the other. Use the user's existing authorized properties. Missing access is unverified; an ineligible online-only business does not need a fabricated local profile.

## Search Console

1. Match property type, domain/protocol/prefix, access scope and site's preferred host. Check available ownership status without changing DNS or account permissions unless authorized.
2. Inspect sitemap processing, page indexing exclusions, URL inspection for priority/template samples, reported selected canonical, last crawl, robots behavior, security/manual-action notices and available enhancements. Separate historical reports from live tests.
3. Establish a search profile from actual exports: queries, landing pages, impressions, clicks, CTR and average position where available; country, device, search type and date range. Distinguish brand/nonbrand with a documented classification. Average position is aggregated, not a stable universal ranking.
4. Compare like-for-like periods and seasons, brand versus nonbrand, page/locale/device and conversion paths. Investigate cannibalization using intent and URL history, not just two URLs sharing a query. Note anonymized queries, reporting limits and attribution/aggregation differences.
5. Inspect Core Web Vitals coverage and distinguish field groups from lab page results. Missing data does not imply passing or failing.
6. Check the current generative AI inclusion control and inherited property setting when accessible, plus available generative AI performance reports. Never silently change an owner's exclusion choice. Preserve the actual report's metric definitions and supported surfaces.

As checked 2026-11-05, Google documents a separate Search generative AI inclusion control and impressions report. Older AI-features documentation describes aggregate Web reporting; use newer specific documentation and actual property availability. Absence of a report can reflect insufficient impressions; it is not proof of zero visibility or a technical failure. Sources: [control](https://support.google.com/webmasters/answer/16908024), [report](https://support.google.com/webmasters/answer/16984139), [Core Web Vitals report](https://support.google.com/webmasters/answer/9205520).

Ownership verification, sitemap submission and indexing requests are actions: execute only within established authority. Report their acceptance separately from actual indexing.

## Google Business Profile and Maps

Assess eligibility, actual ownership/access, verification state, duplicates and public consistency with the website. Inspect business name as used in real life, appropriate categories, contact/address or service-area policy, map location, hours including special hours, website/appointment links, services/products when relevant, photos and genuine reviews. Record checked public profile URL and location; avoid exposing private management identifiers.

Evaluate local query relevance and actual service area. Local visibility depends on factors including relevance, distance and prominence; no profile edit can guarantee a position everywhere. Do not add keywords to a business name unless they are part of its actual name, create fake offices or promise a ranking based on review count. See [Google local-ranking guidance](https://support.google.com/business/answer/7091).

Where authorized/available, compare actual profile-performance data such as website clicks, calls or direction requests using the exact available definitions. A click-to-call interaction is not proof of an answered or qualified call. Keep Maps/local metrics distinct from Search Console website metrics and analytics sessions; don't add them as independent unique users.

Suggest specific accurate corrections. Apply profile edits only when the operational scope covers the external business listing, not merely the website. Prepare review replies if requested; sending them is a separate communication action. Never generate or purchase reviews or filter requests to suppress dissatisfied customers. Record verification/review/platform propagation pending states honestly.
